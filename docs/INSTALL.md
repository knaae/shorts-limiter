# 쇼츠 리미터 설치 안내 (테스터용)

유튜브 쇼츠를 **30분마다 20개까지만** 볼 수 있게 제한하는 브라우저 도구입니다.
설치는 5분 정도 걸리고, PC 크롬(또는 엣지·웨일) 기준입니다.

## 🔒 먼저 알아두실 점

- 시청 기록은 **내 브라우저에만 저장**되고, 어디에도 자동으로 전송되지 않습니다.
- 테스트가 끝나면 메뉴에서 **직접 기록을 내보내서** 보내주시면 됩니다.
- 제목·채널명을 보내기 싫으시면 **"제목·채널 빼고"** 내보내기를 쓰시면 돼요.
- 언제든 확장 프로그램에서 끄거나 삭제하면 원래대로 돌아옵니다.

## 1단계. Violentmonkey 설치

1. 크롬 웹스토어에서 **Violentmonkey** 검색 → "Chrome에 추가"
2. (Tampermonkey를 이미 쓰고 계시면 그걸 그대로 써도 됩니다)

## 2단계. 사용자 스크립트 허용 켜기 ⚠️ 가장 많이 막히는 단계

최근 크롬은 이 설정을 켜야 스크립트가 동작합니다.

1. 주소창에 `chrome://extensions` 입력
2. Violentmonkey의 **"세부정보"** 클릭
3. **"사용자 스크립트 허용"** 토글 켜기
   - 이 토글이 안 보이면, 같은 화면 오른쪽 위 **"개발자 모드"** 를 켜주세요.

## 3단계. 쇼츠 리미터 설치

1. 아래 주소 열기
   `https://raw.githubusercontent.com/YOUR_GITHUB_ID/shorts-limiter/main/src/shorts-limiter.user.js`
2. Violentmonkey 설치 화면이 뜨면 **"설치"** 클릭

## 4단계. 잘 되는지 확인

1. youtube.com/shorts 에 들어가서 쇼츠를 3~4개 넘겨보기
2. 브라우저 오른쪽 위 Violentmonkey 아이콘 클릭 → **"🔍 최근 기록 확인"**
3. 방금 본 영상의 시간·제목이 보이면 성공입니다 🎉
   - 제목이 "(못 읽음)"으로 나와도 제한 기능은 정상 동작합니다. 그대로 알려주세요!

## 메뉴 설명 (Violentmonkey 아이콘 클릭)

| 메뉴 | 설명 |
|---|---|
| 📊 현재 상태 보기 | 이번 구간에 몇 개 봤는지, 내 ID |
| 💾 기록 내보내기 | 시청 기록을 파일(.json)로 저장 |
| 🕶 기록 내보내기 (제목·채널 빼고) | 시간 정보만 저장 |
| 🔍 최근 기록 확인 | 최근 5개 기록 확인 (동작 점검용) |
| 🗑 기록 초기화 | 기록 삭제 |

## 테스트가 끝나면

1. **💾 기록 내보내기** 로 파일 저장
2. 안내받은 방법(카페 쪽지, 메일, 설문 링크 등)으로 파일 전달
3. 짧은 설문에 응답해주시면 끝!

## 삭제 방법

Violentmonkey 대시보드 → 쇼츠 리미터 → 휴지통 아이콘. 기록도 함께 지워집니다.
