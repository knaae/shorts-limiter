# 기능 시뮬레이션 체크리스트 (v1.1.0)

테스터에게 배포하기 전, 개발자가 직접 실제 유튜브에서 확인하는 시나리오입니다.
각 항목마다 **스크린샷**을 남기고 결과(통과/실패, 메모)를 기록하세요. 보고서 "시뮬레이션" 장의 근거 자료가 됩니다.

> 팁: 20개를 매번 넘기기 번거로우면, 스크립트 상단 `CONFIG`를 **WINDOW_MINUTES: 5, MAX_VIDEOS: 3** 으로 바꿔 테스트하고, 끝나면 원래 값으로 돌려두세요. (테스트 설정을 썼다는 점도 기록)

## A. 설치·환경

| # | 시나리오 | 기대 결과 | 결과 | 메모 |
|---|---|---|---|---|
| A1 | Violentmonkey에 설치 | 설치 화면 → 설치 완료 | | |
| A2 | Tampermonkey에 설치 | 동일하게 동작 | | |
| A3 | "사용자 스크립트 허용" 끈 상태 | 스크립트가 동작하지 않음 (안내서 필요성 확인) | | |
| A4 | 첫 실행 후 "현재 상태 보기" | `user-xxxx` 형태 익명 ID 표시 | | |
